# Windows 0.3.1 安全核查与安装验收

日期：2026-11-02。环境：当前Windows11 x64电脑、已安装的卡巴斯基21.21。没有关闭防护、添加排除项或恢复旧隔离文件。

## 证据与判断

旧0.3.0测试EXE的卡巴斯基官方SW2报告记录了进程级PDM:Trojan.Win32.Generic行为检测、终止和回滚，发生在安装展开阶段。该旧EXE未公开发布。

原0.3.0公开ZIP由卡巴斯基官方SCAN只报告模式检查52529个对象，检测0、可疑0、错误0；Playwright1.62.1与Playwright Core1.62.1档案的npm官方SHA512一致，包内保留文件逐字节一致。这说明没有发现已知依赖篡改或静态检出，不等于厂商确认误报。报告没有公开具体行为规则，不能声称已经证明误报或完全定位内部规则。

## 本次实际修改

- 删除发布包的PowerShell引导脚本、ExecutionPolicy Bypass和脚本式隐藏启动链。改为有日志的原生.NET可见配置窗口。
- 标准Inno7 EXE只安装应用文件，不在安装阶段自动配置和运行系统组件。用户从桌面或完成页面主动打开配置窗口。
- 浏览器依赖不再由安装器批量展开；配置窗口从官方npm注册表下载固定版本Playwright Core，校验固定SHA256后进行严格归档解析。下载档案的SHA256由已经核对官方SHA512的同一档案生成。没有混淆、加密依赖或关闭文件扫描。
- 只使用Core API，不捆绑Playwright测试执行器；源码、下载地址、校验值和许可证可检查。
- 归档解析拒绝路径越界、链接、头部损坏及异常大小。Java、MariaDB、Node也固定来源与SHA256，浏览器由对应官方CLI下载。
- 保持目录、数据库和端口隔离；新桌面端首次启动也核对安装目录，拒绝连接其他目录的旧后台。新旧桌面快捷方式分开。
