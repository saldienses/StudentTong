# 学生通：平台与账号

顶部「学习通」「雨课堂」切换平台，右上角「切换账号」选择该平台的账号。每个平台会记住上次选中的账号，重新打开软件时恢复。

## 学习通

已有账号会自动导入账号选择器。手机号以掩码显示。切换后，章节任务、独立作业、考试、签到、复习题库和错题只显示当前账号内容。任务的停止、恢复、删除、作答、提交和复习导出都会检查账号归属。

添加新账号：切换账号 → 去添加学习通账号，输入账号密码并查询课程；成功登录后建立对应账号空间。选择课程再添加任务。查询账号和课程不会自动添加学习任务。

切换账号不会停止其他账号已经运行的任务。切换回原账号后可查看进度并停止。章节执行器使用独立的登录会话，切换操作不会把正在执行的任务改成另一个账号。

自动普通签到按账号分别保存开关和课程选择。首次迁移后各账号自动签到默认关闭，需要重新选择并保存。

旧复习资料的归属根据已有课程任务迁移；无法确定归属的历史记录保留原文件，不合并到任一账号。任务删除后，新版本已保存的复习资料仍留在所属账号。

## 雨课堂

1. 点击顶部雨课堂，再点击切换账号。
2. 添加账号空间：填写一个便于识别的账号名称及学校雨课堂HTTPS入口。默认网址可修改，不要求在学生通中填写平台密码。
3. 点击打开登录 / 平台窗口，在此账号的独立浏览器中完成平台登录，再点击确认已登录。
4. 点击读取当前页面课程。若学校页面没有提供可解析链接，可在独立窗口进入课程，再点击使用当前课程 / 题目地址；也可粘贴地址。
5. 在章节、作业或考试导航下添加对应任务。添加不会立即执行。
6. 点击开始任务，可分别选择AI参考答题和自动提交，两项默认关闭。AI使用设置中的DeepSeek配置。

视频 / 音频运行时显示本媒体播放时间与总时长；题目适配页可显示题号和总数。未勾选自动提交时，已准备的答案会等待确认。遇到无法识别的页面、选项或平台安全验证时，停止自动提交并提示人工核对。平台验证仍须在独立窗口处理。

每个账号同时运行一个浏览器任务；不同账号可保留各自会话。停止任务后可删除任务。关闭学生通主窗口不等于关闭后台和独立浏览器，需要停止时请点停止任务。

可收录已识别页面上的题目到复习模块，并使用现有Word导出和自测。平台公布答案与AI参考答案分开标注。尚未读取到的分页或未访问题目不算已收录全部。

雨课堂签到入口目前提供平台窗口，未实现自动签到。

**验证范围：当前没有雨课堂账号，雨课堂登录、真实课程播放、真实作业 / 考试作答与交卷尚未实测。已完成的是功能接入、账号隔离及离线模拟页面验证。不同学校页面可能需要在有账号后补充适配，不能把离线测试通过当成真实平台交卷成功。**

## 保存位置与扩展

安装和新增数据均在 D:\tool\qita\SuperAutoStudy。

- 账号元数据与任务归属：config\platform-accounts.json。软件接口只返回脱敏账号显示信息。
- 雨课堂账号的浏览器登录资料：data\yuketang\profiles\账号ID。不同账号不共用目录。
- 雨课堂任务：data\yuketang\tasks.json，按账号ID和模块分组。
- 学习通自动签到设置：config\accounts\账号ID\signin-settings.json。
- 复习资料仍在 data\review\library.json，读取和导出时按已保存的账号归属筛选。
- AI设置由本机各平台共享，密钥保留在现有本机配置中，不注入雨课堂网页。

接口在现有开发文档基础上增加 /local/workspace/accounts、/select 和 /local/yuketang/ 下的登录、课程、任务、读题收录入口。客户端发送 X-Study-Platform、X-Study-Account 标识当前操作范围。没有明确选择账号时不返回所有账号混合任务。
