# 签到与位置管理

左侧「签到」显示已添加课程的签到活动、类型、平台进行状态和本机处理记录。

## 普通自动签到

勾选「开启自动普通签到」，选择需要监控的课程，然后点击「保存自动签到设置」。后台每30秒检查这些课程中进行中的普通签到。自动开关默认关闭；关闭客户端不停止后台监控，需要关闭自动签到时请取消勾选并保存。

仅普通签到会自动处理。拍照、手势、二维码、签到码及位置签到不会作为普通签到提交。遇到平台验证码或其他安全提示时，会保留等待状态，沿用设置中的安全弹窗提醒；用户完成平台验证后继续。关闭提醒不代表通过验证。

未开启自动签到时，可在普通签到卡片点击「普通签到」。签到只有在平台页面明确返回成功后才显示「已签到」。网络异常或结果不明时不会自动重复提交，可使用「核对平台状态」只读查询。停止等待不能撤回已发送的签到。

## 位置签到

实际学习通网页要求位置签到使用手机App提供位置信息。Windows端负责地图选点、坐标输入、常用位置及GPX导入导出，不修改Windows系统定位；保存或准备位置不等于已向平台签到。

地图采用WGS84坐标。点击「加载在线地图」后可查看OpenStreetMap底图；点击选点，拖动平移，使用加减按钮缩放。地图不可用时仍可手动输入坐标。输入的纬度范围为-90至90，经度范围为-180至180。在线地图只加载当前可视区域，并在D盘缓存；没有离线批量下载功能。

常用位置可命名、保存、删除，或导出为GPX，在支持GPX导入的手机版本中使用。手机端GoGoGo（影梭）通过Android模拟位置接口运行：按其官方指引授予权限并设置为模拟位置应用，再输入相应位置或导入GPX。百度、高德和GPS坐标系存在差异，不要把未转换的百度/高德坐标直接当成WGS84。

手机位置准备入口可复制纬度、经度，方便输入到GoGoGo；随后仍需在学习通手机App中完成位置签到。没有连接并验证安卓设备时，本软件不会宣称位置签到已完成。

## 数据和扩展

配置：config\signin-settings.json；签到记录：data\signin\records.json；常用位置：data\signin\locations.json；地图缓存：cache\maps。所有路径均位于D盘安装目录。

扩展接口：/local/signin/list、/settings、/start、/stop、/recheck、/locations，以及/locations/add、delete、import、export。位置数据显式标注coordinateSystem=WGS84，便于后续接入手机定位提供者；签到结果与位置管理分别保存。

参考：GoGoGo官方项目 https://github.com/ZCShou/GoGoGo ，借鉴其选点、坐标和位置管理思路；没有将Android应用嵌入Windows。地图数据 © OpenStreetMap contributors，https://www.openstreetmap.org/copyright 。
