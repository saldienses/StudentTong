# 考试功能与安全提醒

考试页读取已添加课程的课程考试列表，显示平台状态、答题进度及本机执行记录。点击「考试说明」不会自动开始作答；点击「开始自动答题」后需要确认进入考试。进入后平台开始计时，停止自动操作或关闭软件并不代表平台计时停止。

可勾选「全部作答完成后自动核验并交卷」。未勾选时，逐题填写完成后等待你在学生通点击「确认提交」。当前已适配逐题展示的单选、多选和判断题。题目含图片或无法解码时沿用已有截图识别设置；未能识别、题序变化或题型不支持时停止，保留说明，不交空卷。

程序使用平台正常考试页面及其脚本，遵循「进入考试→逐题填写→下一题→整卷预览→确认交卷」。不会伪造验证、绕过验证码、人脸校验或专用客户端要求。需要验证时会打开平台窗口，待用户完成后继续。

设置中新增「需要人工处理平台安全验证时弹窗提醒」，默认开启，同一次验证只提醒一次。关闭提醒后仍显示等待验证状态，验证仍需完成。偏好保存在本机 config\client-preferences.json 中。

本机考试作答记录保存在 data\exams。交卷前写入执行标记；结果不明时显示「待平台确认」，禁止自动重复交卷。后台重启后未完成的任务不会自动继续，需核对平台后重新操作。

考试模块保留课程目录、浏览器桥接、题目解析、答题来源和安全提示接口，便于继续扩展其他题型和平台交互。发布程序不包含测试账号、教师登录信息或固定测试课程。
