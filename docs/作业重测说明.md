# 作业平台答案重测

在「作业」卡片中点击「平台答案重测」。程序先读取已提交作业中明确标出的正确答案，显示已公布题数、当前成绩和剩余重做次数。读取阶段不消耗重做次数，已公布答案同步至本机复习题库。

确认弹窗会说明：重做将覆盖上次作答记录及成绩，并消耗一次机会。勾选「匹配完成后自动提交并核验平台状态」时，会在匹配完成后提交；取消勾选则停留在答案草稿，稍后可点击「确认提交」。

重测仅使用平台公布答案，不调用题库或 AI 补齐。当前支持单选、多选和判断题；平台答案不完整、题型不支持、题量变化或无法逐题匹配时会停止。选项换序按选项内容匹配，无法确定则不提交。该功能不保证平台最终成绩一定为满分。

公布答案在调用重做前保存于安装目录 data\homework-retakes。网络异常导致重做结果不明时不会再次调用重做接口。若已进入新答题页，可从保存的平台答案恢复；若平台状态仍不明，需要先核对原平台。

普通作业提交现已补齐网页脚本生成的题号列表，清除暂存标记，并自动读取平台结果页核验完成状态。平台拒绝、登录过期、需要额外验证或提交状态不明时，界面会保留说明，不重复发送交卷。

复习与作业预览会区分平台公布答案、题库参考答案和 AI 参考答案。已公布答案优先。
