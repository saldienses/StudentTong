# SuperAutoStudy 桌面模块 SDK v1

宿主为原生 WPF / .NET Framework 4.8 客户端，不使用 WebView。界面参考 MAA 的侧边模块布局，代码、图标为本项目实现，不调用或修改 MAA。

## 现有模块边界

`chapters` 使用现有本机服务的课程、章节、小测和任务控制接口。`homework`、`exams` 具有独立导航，但默认未接入；不要用章节任务伪装作业或考试结果。

## 注册独立模块

1. 引用 `sdk\StudyDesk.Contracts.dll`，实现 `StudyDesk.Contracts.IStudyModuleProvider`。
2. 编译为 .NET Framework 4.8 类库，放到 `client\plugins`。不要覆盖契约 DLL。
3. 编辑 `client\modules.json` 对应条目，设置 `assembly`（相对 plugins 的 DLL 路径）、`type`（完整类型名）和 `enabled: true`。
4. 重启客户端。`Id` 必须为 `homework` 或 `exams`。模块配置错误会显示加载失败，不会退回虚构结果。

只安装自己审核和信任的本机扩展，扩展 DLL 在客户端进程内运行。默认两个扩展均关闭，未注册的 DLL 不会被自动扫描执行。

## 接口

```csharp
public interface IStudyModuleProvider {
    string Id { get; }
    void Initialize(IServiceClient service);
    Task<ModuleSnapshot> LoadAsync(CancellationToken cancel);
    Task<string> ExecuteAsync(string action, string taskId, CancellationToken cancel);
}
```

`LoadAsync` 为只读操作，每 3 秒调用。必须返回真实任务，不要在此方法中提交答案、创建任务或改变平台进度。`ModuleSnapshot.Available=false` 会显示 `Message`，不显示操作按钮。

`StudyTask` 包含 `Id`、`Title`、`State`、可空 `Progress`、`Detail`、`Live` 和 `Actions`。无进度返回 null，不要伪造 0 或 100。

常用 Actions：`resume`、`stop`、`rescan`、`delete`。宿主在用户确认后调用 `ExecuteAsync`，不会因轮询自动执行。模块仍须由后端检查任务归属、状态和重复提交。Actions 应只返回当前可用的操作。

Live 可携带 `active`、`phase_label`、`chapter_title`、`video_duration_seconds`、`video_estimated_seconds`、`video_reported_seconds`、`question_index`、`question_total`、`prepared_questions`、`answer_source`、`recognition_source`。

## 共享服务接口

`IServiceClient.RequestAsync(path, body, cancellationToken)` 只访问 `http://127.0.0.1:3030`。

- body 为 null：GET；否则 POST JSON。
- 统一返回 JSON 对象；含 code 时必须为 200，否则抛错。
- 不允许外部 URL、双斜杠地址、反斜杠路径。
- 不要通过 Live、错误消息、日志或 UI 回显密码、Cookie、API Key。

现有接口：

| 用途 | 路由 |
|---|---|
| 状态和章节任务 | GET /local/status |
| 课程查询 | POST /chaoxing/course |
| 添加章节任务 | POST /chaoxing |
| 任务操作 | POST /local/tasks/{id}/{resume,stop,rescan,delete} |
| AI 配置读取 / 保存 | GET / POST /local/ai/config |
| AI 连接验证 | POST /local/ai/test |

独立作业和考试应由后续后端适配器提供新的接口，例如 `/local/homework/...`、`/local/exams/...`。这些路由当前不存在。需要另外完成平台登录会话隔离、题目读取、提交结果确认和恢复策略，不能仅改变路由名称就宣称已接入。

## 示例和源码

`sdk\examples\ExampleProvider.cs` 和 `Example.Provider.dll` 是可编译、可加载的只读占位示例，未实现平台作业 API，默认不启用。

在示例配置中可使用 `assembly: Example.Provider.dll`、`type: Example.HomeworkProvider`、`id: homework`。启用后只会显示说明，不执行任务。

完整桌面源码和构建脚本位于 `development`。直接运行 `development\build.ps1`，输出到其 `bin`；使用系统自带 .NET Framework C# 编译器，不需要下载 SDK。

宿主关闭不会停止后台课程。后台服务与客户端分离，扩展中的长请求应支持 CancellationToken，提交操作应由后端持久化确认状态。
