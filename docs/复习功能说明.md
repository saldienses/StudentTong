# 学生通参考判分与学习通AI

## 复习自测

在“复习”中勾选“无平台答案时允许题库 / AI 参考判分”，再点击“开始自测”。这个开关默认开启；取消后仍保持只使用平台公布答案的严格模式。

有平台公布答案时优先按平台答案判分；没有时，在首次提交本题的作答时查询参考答案。来源依次为题库、学习通AI，最后回退到已配置并启用的 DeepSeek。不会启动时批量生成 422 道题的参考答案。

判分界面、错题记录、Word 和 JSON 导出均区分：

- 平台公布答案。
- 题库参考答案。
- 学习通AI参考答案。
- AI参考答案（DeepSeek 后备）。

参考答案不是平台标准答案，可能有误。参考判分会用“参考判分认为答对 / 答错”提示，错题记录会同时保留判分来源。平台以后公布答案，重新收录后会优先使用新平台答案。

参考答案保存在本机题库，重复练习同一道题不会反复查询。题干或选项变化后会使旧参考答案失效。单选、多选、判断题按对应选项判分；填空按答案文字精确匹配，多空用 # 分隔。内容不完整或不支持的题型不会猜测判分。

## 平时学习任务中的学习通AI

设置页新增“启用学习通AI讲解作为答题后备来源”。章节小测和独立作业的题库无答案时，会尝试学习通题目讲解助手；不可用、限流或回复无法解析时，回退到已启用的 DeepSeek。题库命中时不额外调用 AI。

学习通AI复用本机保存的学习通账号会话，不需要另填 API Key。登录过期或权限变化时，重新查询课程登录后再试。此接入使用平台实际返回的应用和会话参数，不生成或替换平台签名。只有已验证的题目讲解助手回复格式才会被使用。

设置页“测试学习通AI”会发出一道简单连通题。请先保存启用开关；测试不提交作业或考试。

DeepSeek 继续作为独立后备，需要现有 API Key，调用可能产生费用；学习通AI使用平台账号的可用权限与额度。软件不保证 AI 答案正确。

## 保留边界

复习作答只在本机判分，不向学习通提交成绩或作答。原有学习任务的自动提交设置不因本次升级改变。考试已接入自动作答和交卷；复习收录目前仍不包含考试试卷。

本次验证包括流式回复、提供方优先级、来源标注、缓存、平台答案覆盖参考答案和参考错题持久化。真实连通验证使用简单测试题；没有批量回答或提交真实作业。
