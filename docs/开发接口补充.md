# 平台与账号接口

IServiceClient契约保持兼容。原有学习通Provider继续使用原路径；ServiceClient对请求附带当前平台与账号快照。切换时清除旧页面和缓存，丢弃旧范围的异步响应。

GET /local/workspace/accounts 返回平台、各平台选中账号ID与脱敏账号列表。POST /local/workspace/select 接收 {platform,accountId}。platform取chaoxing或yuketang。

账号请求头：X-Study-Platform、X-Study-Account。账号ID必须存在并与平台一致。缺少请求头时使用本机当前选择。未选账号时不会降级为全部账号。后台线程不使用UI当前选择，始终使用任务保存的账号。

GET /local/status、作业/考试/签到列表和复习接口按此范围处理。列表缓存包含范围；按任务ID进行操作时先校验归属，跨账号请求返回403。

雨课堂：POST /local/yuketang/accounts/add 接收label、entry；POST /login 打开独立会话；POST /login/confirm 确认会话；GET /courses 和 /current 读取课程链接；GET /tasks?module=chapters|homework|exams 返回任务。

POST /tasks/add 接收title、url、module。POST /tasks/start 接收id、autoAI、autoSubmit、confirmed；自动提交需要confirmed=true。POST /tasks/stop、/tasks/delete、/tasks/submit 均校验任务归属。POST /review/collect 接收course任务ID，收录当前对应页面，不发起作答。

雨课堂桥接协议采用JSON行和关联请求ID，普通网页不会获得本机DeepSeek密钥。浏览器状态事件携带任务ID，服务端以进程绑定账号和当前任务双重匹配后写入。浏览器的登录资料分别保存在账号UUID目录下。启动任务需要重新确认有效会话；不自动登录测试账号，不硬编码课程、学校账号或密码。

新增平台可复用账号元数据与UI顶部切换布局，提供自己的任务存储、会话桥接和模块页面。能力未接入时明确显示状态，不复用另一平台的题目或提交动作。
