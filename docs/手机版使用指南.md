# 学生通手机版 0.2

## 安卓安装

将“学生通-Android-0.2.0.apk”传到手机，点击安装。系统询问时，仅为你用于打开此APK的文件管理器允许安装此来源。最低Android 9，APK为本机发布签名包。MuMu中已安装同一份正式APK。

首次使用：切换平台 → 切换账号 → 添加独立账号空间 → 输入便于识别的账号名称及平台HTTPS入口 → 在App内的平台页面登录。名称不是平台密码；软件没有内置正式或测试账号。

每个账号使用独立浏览器资料目录，任务、题库、错题和AI设置分别保存。安卓版本当前最多支持16个账号空间。手机号登录和学号登录如果分别建立空间，会作为不同本机空间管理。

## 学习与任务

在“学习”页切换章节/作业/考试/签到分类，打开相应平台内容。“保存任务”记录当前页面，归入所选分类。任务页提供继续、停止、删除。

媒体进度来自App前台能读取到的播放器实际时间；页面跨域或未开放播放器信息时不显示假进度。视频播放结束标为“待平台核对”，不直接认定平台课程已完成。

手机端不依赖Windows服务，不运行Windows数据库；也不提供全天后台刷课、自动考试交卷或模拟定位。正式作业、考试和签到仍在平台页面由你确认。平台要求官方客户端时，本工作台不能替代其专用客户端验证。

切换账号、退到后台或锁屏可能暂停学习，手机版不是后台挂机工具。平台验证码、人脸或其他安全验证须人工完成。

## 题库与自测

“收录题目”只收录当前可读取页面，不代表自动遍历整门课程。图片题、跨域嵌入题目或未适配页面可能无法读取，程序不会编造题目。

也可在Windows版的复习模块导出JSON，在手机复习页导入。导入只进入当前账号。正确答案优先采用平台公布答案，没有平台答案时可使用明确标注的AI/题库参考答案。

开始自测后，答对进入下一题；答错标记错题，显示答案和来源，点击下一题继续。“只练错题”筛选本账号错题。没有可判分答案的题目仅可查看。

安卓支持导出题库JSON和可打印的HTML复习页（可用支持打印的应用保存为PDF）。JSON能在Windows、Android和iOS工程之间手动传递；导出文件不包含登录Cookie和AI Key。

## AI设置

设置页填写当前账号的DeepSeek Key和模型，保存后输入框清空，留空保存会保留原Key。Key使用Android密钥库加密。AI讲解会把你选择的题干和选项发送到DeepSeek，可能产生API费用；界面明确确认后才发起请求。答案标为AI参考，不自动填答、交作业或交卷。

## 苹果版本

“学生通-iOS工程.zip”是iOS 17及以上的原生SwiftUI工程，包含同一图标和主要移动学习功能。你已选择先交付工程和安装方案。

本次没有Mac或Apple签名环境，因此没有生成、签名或实测IPA，不能直接在iPhone打开ZIP安装。后续需在Mac用Xcode构建，选择自己的签名Team后安装真机。具体步骤见工程内README.md。

Windows版和安卓版共用基于用户原图去除外部白底后的图标。白猫和原图内部颜色保留；iOS图标按Apple要求保存为不透明蓝色背景版本，不保留外部白边。

默认AI模型按[DeepSeek官方当前模型文档](https://api-docs.deepseek.com/quick_start/pricing/)设置为deepseek-flash；可在设置中修改。当前讲解使用非思考模式的JSON回复。

## 0.2 签到中心

安卓底部新增“签到”。先打开当前账号的独立空间，在学习页登录并进入课程，再从签到中心读取当前页或粘贴课程/活动链接，刷新活动。

普通签到：打开活动，点击“确认签到”，确认后等待平台回执。位置签到：打开活动，点击“获取本机位置”，允许系统精确定位，核对定位来源、精度及坐标后提供给页面，再点击“确认签到”。位置仅来自系统定位；不会把保存位置、读取活动或准备坐标当成签到成功。

位置页显示系统WGS84和平台BD09两种格式，自动转换。仅接受两分钟内、有效精度的定位。模拟器可用自身定位工具设置测试位置，确认框如实显示系统返回的定位来源和模拟标记。平台限制范围、验证码、人脸验证仍由平台处理；需要人工处理时可按账号设置开启提醒。

提交后等待真实回执。未确认结果时不会重复发起，使用“核对结果”只读检查。活动记录和课程选择只保存在当前账号空间。

本次在自建“测试”课程发布位置签到，并在MuMu完成定位、明确确认、平台success回执及发布端人数核对（1/1）。测试活动未设置指定位置范围，不能据此宣称所有学校的位置限制或手机客户端专有验证都已适配。iOS工程本次没有迁移此原生签到中心，尚未构建或实测。
