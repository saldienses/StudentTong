# 学生通 Android 0.3.0

原生Java+WebView，Android9及以上；沿用0.2.0的包名、数据库、账号空间和发布签名。安装0.3.0 APK可覆盖升级，旧0.2.0 APK保留。没有清空原数据库，也没有移植Gradle或更换SDK/JDK。

## 页面

顶部切换平台和账号；底部学习、任务、签到、复习、设置。学习页保留平台WebView，使用紧凑的分类、保存任务、收录题目、AI讲解和更多菜单。任务删除先确认。复习保留题库导入导出、自测、错题与答案来源。设置保留AI Key加密与可选安全提醒。

## 地图选点

选择账号 → 签到 → 地图选点。地图使用本地Leaflet1.9.4，内部坐标为WGS-84；可点击、拖动和双指缩放。搜索地点由你主动点击后发送到所选地理服务，默认Nominatim；搜索或底图不可达时，点击“坐标”手动输入。不会把GCJ02或BD09坐标当作WGS84直接发布。

“◎本机”读取GPS/网络Provider的非Mock系统定位：绿色为设备位置，蓝色为选中位置。模拟器返回的非Mock位置仍属于模拟器环境，不能证明真实手机GPS精度。

底部保存位置和历史均按账号保存，可使用和删除。“确认选点”只保存本地选点，不会启动系统模拟，也不会直接提交签到。

“本地路线预览”：先将选点设为起点，再选终点，开始后橙点沿直线运行约30秒；支持暂停、恢复、停止。动画只在地图中显示，不发布到Android系统，也不进入签到接口。切至后台会暂停预览。

## 官方系统模拟定位

若系统没有显示开发者选项，可先在“关于手机”中连续点击版本号开启（MuMu本次按此流程完成）；不同手机入口以系统界面为准。首次使用必须由你手动选择：系统设置 → 开发者选项 → 选择模拟位置信息应用 → 学生通。应用提供打开开发者选项及重新检查授权的入口，不会自行更改安全设置。

在“系统模拟定位”中开始，设置间隔（1至60秒）、精度（1至2000米）、海拔、速度、方向及教师允许的修正原因。确认提示后才启动前台服务；Android13及以上还需允许通知。只有系统接口实际回读到对应坐标且Mock标记为真，才显示运行中。

使用独立的studenttong_测试Provider，不替换系统gps/network Provider。其他应用是否选用独立Provider取决于其实现，不能保证所有第三方App都使用该位置。应用不会隐藏Mock标记；平台不接受时应按其要求处理。

可以从模拟管理中暂停、恢复、停止，也可点击通知栏“停止”。暂停与停止都会移除本模块创建的Provider。停止不伪造“真实位置恢复”坐标；正常定位仍需设备GPS或网络服务实际提供。异常退出后重启会检查已记录的本模块Provider并尝试清理，不自动恢复模拟；清理未确认时如实显示异常。

## 签到数据流

普通定位：Android系统定位 → 原有SigninUi读取 → 用户查看并确认 → 原平台签到 → 官方回执核对。

模拟定位：地图WGS84选点 → 官方TestProvider发布 → Android系统真实回读带Mock标记的Location → 原有SigninUi读取 → 用户确认 → 原平台验证。

地图和路线预览没有直接调用provide/confirm/submit的接口。进入原平台位置页时，仅把系统读取的WGS84转换一次为平台BD09；原平台请求格式、人工验证与结果核对逻辑保留。

“准备位置”“启动服务”“发送请求”都不等于平台已签到。未知回执、风控、操作频繁、人脸或验证码会明确提示，安全弹窗可在设置中开关；不会绕过或自动重试限制。

## 诊断和记录

签到中心和设置可进入定位诊断，查看真实Provider、定位坐标、精度、时间、Mock标记、授权、注册及服务状态。当前位置与最近一次验证位置分开显示。修正记录包含原位置（未取得则明确缺失）、所选位置、原因和开始/结束时间，按账号保存，支持删除，不自动上传。

地图只请求可见瓦片，按HTTP缓存策略缓存并限制数量，不提供批量离线抓取；保留OpenStreetMap署名。模拟管理中的地理服务与底图设置支持切换有权使用的HTTPS服务，不内置API Key。地点查询和地图瓦片请求会向相应服务发送查询/可见区域信息，历史和修正记录不随查询上传。

## 本次测试边界

仅连接MuMu Android12/API32，没有真实安卓手机。Android9、13、14及更新系统的真机兼容性尚未实测，尤其通知和前台服务限制仍需逐机验证。当前MuMu访问Nominatim超时，默认在线底图也不可达，在线搜索、逆地理编码及底图显示不能列为通过；本地坐标选点、拖动缩放、历史和路线功能已实际操作验证。

已在自建测试课程发布0.3.0位置活动；学生端活动接口返回“请勿频繁操作”，本轮已停止第三方自动请求，没有验证平台接受Mock签到，不沿用0.2.0的成功结果冒充0.3.0结果。

MuMu会自动同意定位运行时授权，因此本轮未验证真实系统拒绝弹窗。未授权Mock应用、权限检查及异常处理均保留，真机仍需逐项验证。
